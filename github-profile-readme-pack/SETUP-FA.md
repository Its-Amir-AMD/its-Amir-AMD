# راه‌اندازی Profile README

1. در GitHub مخزنی عمومی با نام دقیق `Its-Amir-AMD` بساز؛ نام مخزن باید دقیقاً با نام کاربری‌ات یکی باشد.
2. فایل `README.md` را در ریشهٔ مخزن قرار بده و Commit کن. همین فایل در صفحهٔ پروفایل نمایش داده می‌شود.
3. برای فعال‌شدن انیمیشن مارِ نمودار مشارکت، فایل `.github/workflows/snake.yml` را هم با همین مسیر در مخزن قرار بده.
4. در تنظیمات مخزن، بخش **Settings → Actions → General → Workflow permissions** را باز کن و مطمئن شو گردش‌کارها اجازهٔ نوشتن محتوا دارند. در صورت نیاز، گزینهٔ **Read and write permissions** را فعال کن.
5. به تب **Actions** برو و گردش‌کار **Generate contribution snake** را با **Run workflow** اجرا کن. پس از موفقیت اجرای اول، شاخهٔ `output` و تصویر مار ایجاد می‌شود.

بخش‌های آمار، نمودارها، شمارندهٔ بازدید و تایپ متحرک از سرویس‌های بیرونی استفاده می‌کنند؛ بنابراین در صورت اختلال موقت آن سرویس‌ها، ممکن است بعضی تصاویر دیر بارگذاری شوند.
